# 🚀 Getting Started

## 1️⃣ Clone Repository

```bash
git clone <repository-url>

cd InvestiGator
```

---

## 2️⃣ Backend Setup

```bash
cd backend

pip install -r requirements.txt
```

Run the API

```bash
python -m uvicorn app.main:app --reload --port 8000
```

Backend:

```text
http://localhost:8000
```

---

## 3️⃣ Frontend Setup

```bash
cd frontend

npm install

npm run dev
```

Frontend:

```text
http://localhost:5173
```

---

## 4️⃣ AI Setup (Optional)

Install Ollama

```bash
ollama run deepseek-r1:1.5b
```

This enables the AI Investment Advisor for local financial analysis.
